# 편집 도구

상단 도구막대에서 도구를 고르고 이미지 위에 그립니다. 선택한 객체는 상단 속성 행에서 색·크기·스타일을 바꿉니다. 조절점은 화면 확대와 관계없이 잡기 쉬운 크기로 표시합니다.

- **화살표 A / 선 L**: 시작·끝 핸들로 길이와 방향을 수정합니다. 화살표 가운데 핸들을 끌면 곡선이 됩니다. 채운 몸통·열린 곡선 촉·가는 촉·양방향 스타일을 제공합니다. Shift는 45도 단위 각도로 고정합니다.
- **텍스트 T**: 클릭해서 입력하고 Enter로 줄바꿈, Ctrl+Enter로 완료합니다. 더블클릭으로 재편집하고 Esc로 취소합니다. 입력과 완료 후 같은 폭으로 줄바꿈하며, 긴 말풍선은 높이와 캔버스를 확장합니다. 수동으로 바꾼 폭과 꼬리 위치는 재편집해도 유지합니다.
- **번호 N**: 클릭하면 번호가 증가합니다. 선택 후 숫자 키로 0–99를 입력하면 다음 번호도 이어집니다. 포인터를 켜고 끝 핸들로 방향을 바꿀 수 있습니다.
- **사각형 R / 타원 O**: 테두리·반투명·단색·사선 채움과 손그림 마감을 고릅니다. 말꼬리를 켜면 끝 핸들을 이동할 수 있습니다. Shift는 정사각형·원으로 제한합니다.
- **펜 P**: 드래그로 곡선을 그리고 한 번 클릭하면 점을 남깁니다.
- **형광펜 H**: 마커 선·자유 그리기·사각 영역, 평평한·둥근·손그림 끝 마감을 제공합니다.
- **모자이크 M / 흐림 B / Erase E**: 사각 범위를 그려 처리합니다. 이동 중에는 실제 효과를 축소 미리보기로 보여주고, 놓은 뒤 원래 해상도로 확정합니다. 텍스트만 처리 기능은 로컬 OCR 인식 영역을 사용합니다.

선택 V에서 객체를 이동합니다. Alt+드래그 또는 Ctrl+D는 복제, Delete는 삭제, Ctrl+Z/Y는 Undo/Redo입니다. 방향키를 누른 동안의 반복 이동은 한 번에 Undo합니다. Ctrl은 이동 중 정렬 맞춤을 잠시 끕니다.

Ctrl+휠은 포인터 아래 위치를 기준으로 확대합니다. 스크롤 끝에서는 위치 유지가 제한될 수 있습니다. 확대 상태에서 객체를 보기 가장자리로 끌면 자동 스크롤합니다. 기존 객체를 이미지 밖으로 옮기면 내보내기에서 해당 부분이 잘리며 Undo로 복구할 수 있습니다.

스포이트 I는 클릭으로 전경색, Shift+클릭으로 배경색을 고르고 HEX를 복사합니다. 패널에서 RGB·HSL·OKLCH 형식과 WCAG 2 대비·APCA Lc를 확인합니다. 배경 꾸미기(▣)는 그라데이션·단색·투명 배경, 여백, 둥글기, 그림자를 바꾸며 Undo할 수 있습니다. 선택 도구 V에서 빈 곳을 드래그하면 범위 상자가 생깁니다. 상자 안을 드래그해 옮기고 조절점으로 크기를 바꾸며, Enter는 자르기, Delete는 그 범위를 Erase 객체로 지우기, Esc는 취소입니다. 범위 상자와 자르기 범위는 방향키(Shift 10px)로 이동, Alt+방향키로 크기, [ ]로 확장·축소, A로 단색 여백을 제거해 내용에 맞춥니다. Ctrl+2는 자르기 범위나 선택 객체를 화면에 맞춰 확대합니다. 아무것도 선택하지 않은 상태의 Esc는 편집창을 닫으며, 설정에 따라 먼저 복사·저장합니다.

영구 편집 프로젝트는 저장하지 않습니다. PNG/JPEG는 주석을 합친 이미지입니다. [추가 도구](advanced-tools.ko.md)와 [전체 사용 안내](START-HERE.ko.md)를 참고하세요.

## 스타일과 선택 피드백 (0.8.0)

도구를 고른 후 상단 **프리셋**에서 실제 결과 미리보기를 선택하세요. 선택한 객체에 즉시 적용되며 다음 그리기에도 같은 스타일을 사용합니다. 색상·굵기·채움은 이후 개별 조절할 수 있습니다. 형광펜은 기본 노란 마커, 도형은 얇은 테두리로 시작합니다.

선택 모드에서 객체를 가리키면 파란 테두리와 이동 커서가 표시됩니다. 흰 사각 핸들은 크기, 파란 원은 말꼬리 방향·길이, 흰 마름모는 화살표 곡률, 민트색 마름모는 모서리 둥글기입니다. 각 조절점의 역할은 하단에 표시됩니다. 말꼬리 너비와 모서리 반경은 속성 행에서 수치로 확인하며 조절할 수 있습니다. 텍스트는 다른 도구를 사용하는 중에도 더블클릭하여 편집할 수 있습니다.

속성 행은 이미지 위를 덮지 않고 편집 영역 위에 배치됩니다.

크기·반경·꼬리 너비는 숫자를 직접 입력하고 Enter로 적용할 수도 있습니다. Esc는 입력을 취소합니다. 합성 이미지로 별도 편집창을 시험하려면 `Snaplet.exe --editor-demo`를 실행하세요. 실행 중인 캡처 세션과 분리되며 데모 창을 닫으면 데모 프로세스가 종료됩니다.

텍스트를 입력하는 동안에도 말풍선의 배경·둥글기·꼬리를 볼 수 있습니다. 새 말풍선은 여러 줄로 커져도 기본 꼬리가 몸통에 묻히지 않도록 위치를 정합니다. 이미 직접 옮긴 꼬리는 재편집할 때 그 위치를 보존합니다. 일반 글자 입력은 이미지 위에서 투명한 배경을 사용합니다.

둥글기 조절점은 글자를 가리지 않도록 도형 바깥에 점선으로 연결됩니다. 안쪽으로 끌면 둥글어지고, 바깥으로 끌면 각진 형태가 됩니다. 너무 작은 객체나 여백이 없는 위치에서는 속성 행의 수치로 조절하세요. 조절점을 클릭만 해서는 Undo 이력을 만들지 않습니다.
