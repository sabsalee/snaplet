# Windows 11 x64 실사용 확인

이 문서는 통과 기록이 아니라 실제 PC에서 확인할 체크리스트입니다. 자동 검사 범위는 [검증 문서](TESTING.md)에 별도로 기록합니다.

2026-10-16에는 Windows 11 원격 세션에서 0.8.1의 `--editor-demo`와 합성 이미지를 사용해 화살표 생성·곡률 드래그·프리셋 적용, 영문 말풍선 생성·재편집, 꼬리 위치와 모서리 둥글기 드래그를 확인했습니다. 입력 시작·종료 시 캔버스가 움직이는 문제를 발견해 0.8.2에서 수정하고 Windows 자동 재발 검사를 추가했습니다. 아래 목록 전체의 통과를 의미하지 않으며, 수정 빌드의 같은 원격 환경 재검사는 별도입니다.

1. 설치 파일로 설치하고 시작 메뉴·트레이·단축키를 확인합니다. 기존 ZIP 버전은 먼저 트레이에서 종료합니다.
2. 영역·창·모니터·지연·반복 캡처를 실행하고 Esc로 취소합니다. 다른 앱이 포커스를 가진 상태에서도 단축키를 확인합니다.
3. 곡선 화살표·말풍선·번호·도형의 생성, 재선택, 핸들 조절, 스타일 변경, 복제, Undo/Redo를 반복합니다.
4. 한글 IME 조합·백스페이스·Enter·Esc·Ctrl+Enter·바깥 클릭과 긴 글 재편집을 확인합니다. 입력 전후 폭·꼬리 위치가 유지되고 글자가 잘리지 않아야 합니다.
5. Ctrl+휠 확대 기준점, 방향키 반복 이동의 Undo, 경계 드래그·자동 스크롤, 모자이크·흐림·Erase의 실제 미리보기를 확인합니다.
6. PNG/JPEG·클립보드·파일 드래그로 다른 앱에 전달하고, 선택 핸들·입력창이 내보내기에 포함되지 않는지 확인합니다.
7. 100/150/200% 배율과 서로 다른 배율의 모니터 사이에서 포인터·핸들·고정 이미지·팝업을 확인합니다. 잠금·절전 복귀도 확인합니다.
8. 설정 → 업데이트에서 확인·다운로드·재시작을 실행하고 설정이 유지되는지 확인합니다. 오프라인·다운로드 중 종료·취소 뒤에도 기존 버전이 실행돼야 합니다. 캡처·저장·복사 중 재시작은 막아야 합니다.

## 0.9 추가 확인

9. 영역 선택에서 확대경의 좌표·색이 실제 픽셀과 맞는지, 100/150/200% 배율 모니터에서 확인합니다. Tab으로 복사한 HEX를 다른 앱에서 비교합니다.
10. Ctrl을 누른 채 놓아 조정 단계로 들어가 방향키·Alt+방향키·[ ]·A·Enter를 확인합니다. 두 번째 모니터에서 드래그를 시작하면 첫 모니터 선택이 지워져야 합니다.
11. 텍스트·QR 바로 인식으로 화면의 QR 코드와 한글 문장을 각각 읽어 클립보드 내용을 확인합니다.
12. 브라우저 긴 문서에서 자동 스크롤을 실행해 고정 헤더·푸터가 한 번만 남고 끝에서 멈추는지 확인합니다. 진행 창이 선택 영역을 가리지 않아야 합니다.
13. 배경 꾸미기·포인터 포함·창 캡처 그림자·내보내기 크기의 결과를 PowerPoint·메신저에 붙여넣어 확인합니다.
14. 이전 버전 설정 파일을 둔 채 0.9로 업데이트해 단축키가 유지되는지 확인합니다.

최근 캡처와 편집 객체는 앱 종료 시 사라집니다. 업데이트 전 필요한 결과를 저장하세요. 캡처 지연은 [성능 측정](capture-performance.md)의 구간 로그를 사용하며, 합성 렌더링 검사 시간을 실제 캡처 시간으로 해석하지 않습니다.
