# Snaplet · Windows 11 x64

자동 업데이트를 사용하려면 Releases의 **Setup.exe**를 한 번 설치하세요. 기존 ZIP 실행 버전은 트레이에서 먼저 종료합니다. 설치 후 설정 → 업데이트에서 확인·다운로드·재시작을 할 수 있습니다. 기본값은 자동 확인·다운로드이며 작업 중 강제 재시작은 하지 않습니다. 자세한 내용은 [업데이트 안내](UPDATING.md)를 참고하세요.

설치 없이 쓰려면 ZIP 전체를 한 폴더에 풀고 Snaplet.exe를 실행합니다. ZIP 실행 버전은 자동으로 파일을 교체하지 않습니다. .NET은 포함되며 ZIP 버전에서 OCR 엔진 로드 오류가 나면 Microsoft Visual C++ x64 런타임을 설치하세요.

## 빠르게 사용하기

- Ctrl+Shift+1: 영역 캡처. 드래그 후 놓으면 완료, Esc로 취소. 확대경으로 픽셀 위치·색을 보고 Tab으로 색상 코드를 복사합니다. Ctrl을 누른 채 놓으면 조절점·방향키·A(내용에 맞춤)로 다듬은 뒤 Enter로 캡처합니다.
- Ctrl+Shift+2: 활성 창 캡처.
- Ctrl+Shift+3: 마우스가 있는 모니터 캡처.
- Ctrl+Shift+4: 3초 후 화면 캡처.
- Ctrl+Shift+5: 최근 캡처 편집.
- Ctrl+Shift+6: 직전 영역 반복 캡처.

모든 화면·창 선택·스크롤·텍스트/QR 바로 인식·Snaplet 열기도 설정 → 단축키에서 지정할 수 있습니다(기본 미지정, Backspace로 해제). 키가 다른 앱과 겹치면 설정 → 단축키에서 조합을 바꿉니다. 설정은 캡처·단축키·저장·정보 페이지로 나뉘며 변경 사항 저장을 눌러 적용합니다. 시스템 트레이 메뉴에는 창 선택, 모든 화면, 수동 스크롤 캡처도 있습니다. 창을 닫아도 상주하며 종료는 트레이 메뉴에서 선택합니다.

작은 미리보기에서 편집·복사·저장·OCR·고정을 선택하세요. 이미지를 드래그하면 PNG 파일로 전달합니다. 고정된 창은 새 캡처와 바깥 클릭에도 유지됩니다. 고정 창의 휠로 크기를 바꾸고 오른쪽 드래그로 이동합니다. 고정한 이미지의 도구는 마우스를 올리면 나타납니다. 작은 미리보기에서 편집을 누르면 미리보기는 닫히고 편집창이 열립니다.

## 편집

화살표·선·사각형·원·펜·글자·번호·형광펜·모자이크·흐림·불투명 가림을 제공합니다. 선택 모드에서 객체를 움직이고 핸들로 수정합니다. 자르기와 복원, Undo/Redo, 확대/화면 맞춤, PNG/JPEG 저장을 지원합니다. 보기용 선택 핸들은 저장되지 않습니다.

Ctrl+휠로 포인터 아래 위치를 기준으로 확대하고 오른쪽 버튼 또는 Space+드래그로 이동합니다. 키보드 확대는 화면 중심을 기준으로 합니다. 스크롤 끝에 닿아 더 이동할 수 없는 경우 기준점 유지는 제한됩니다. 객체를 드래그해 보기 영역 가장자리로 가져가면 자동 스크롤하며, 기존 객체는 이미지 경계를 넘어 이동할 수 있습니다. 경계 밖 주석은 내보내기에서 잘리며 Undo로 되돌릴 수 있습니다. 모자이크·흐림·Erase는 추가 이미지와 앞선 주석에도 적용합니다. 텍스트 추출 버튼과 텍스트만 처리 기능은 로컬 OCR을 사용합니다. 텍스트 추출 버튼은 현재 자른 범위의 편집 결과를 읽습니다.

저장한 PNG/JPEG는 편집 결과를 합친 이미지입니다. 앱을 다시 시작해 객체 편집을 계속할 수 있는 프로젝트 파일 형식은 아직 없습니다. 같은 캡처의 편집창을 다시 열면 보관 중인 객체 상태가 유지됩니다. 오래된 숨김 문서는 메모리 한도에서 해제될 수 있으므로 필요한 결과는 저장하세요.

상단 아이콘으로 도구를 고르고, 선택 객체의 색·크기·스타일은 우측 상단 패널에서 바꿉니다. 화살표 가운데를 드래그하면 곡선이 됩니다. 텍스트는 T → 이미지 클릭 → 직접 입력 → Ctrl+Enter로 완료하며 더블클릭으로 수정합니다. 입력 중과 완료 후 같은 폭으로 줄바꿈하며, 도형의 흰 핸들로 폭을 바꾼 뒤 다시 입력할 수 있습니다. 긴 말풍선은 높이가 늘고 필요하면 캔버스도 확장됩니다. Esc는 변경을 취소합니다. IME 조합 중에는 먼저 조합을 끝내세요. 최대 8,192자를 입력할 수 있고 캔버스 한도 초과 시 입력을 보존해 수정할 수 있습니다. 말풍선 꼬리 끝을 드래그해 방향과 길이를 바꿉니다. 번호는 선택 후 숫자 키로 수정하고 다음 번호는 수정 값에서 증가합니다. 번호 포인터는 길이 제한이 있습니다.

화살표는 채운 몸통·열린 곡선 촉·가는 촉·양방향 중 고릅니다. 번호는 곡선으로 이어지는 물방울 포인터, 말풍선은 둥근 연결부를 사용합니다. 사각형·타원 속성에서 손그림과 사선 채움을 선택할 수 있습니다. 도형 생성 후 **말꼬리**를 켜면 끝에 흰 핸들이 생깁니다. 핸들을 끌어 방향과 길이를 바꾸고, 꼬리를 껐다 켜도 위치를 유지합니다. 펜은 입력 점 사이를 부드러운 곡선으로 연결합니다. 도구별 색·크기·스타일을 창이 열려 있는 동안 기억합니다. Shift+드래그는 선·화살표 각도를 45도 단위로 고정하고 새 도형을 정사각형·원으로 만듭니다. 객체 이동 중 정렬 가이드는 Ctrl로 잠시 해제하거나 ··· 메뉴에서 끕니다.

C로 자르기 모드에서 영역을 선택·재조정한 뒤 Enter로 적용하세요. Alt+드래그 또는 Ctrl+D로 복제, 방향키로 1px·Shift+방향키로 10px 이동합니다. 방향키를 누르고 있는 동안의 반복 이동은 마지막 키를 놓을 때 Undo 한 번으로 묶습니다. ··· 메뉴에 추가 도구와 OCR/복원이 있습니다. 복사·저장 후 숨기기는 하단에서 끌 수 있습니다. Ctrl+Shift+S는 다른 이름으로 저장입니다.

## 추가 편집 도구

··· 메뉴 또는 G(돋보기), S(Spotlight), E(Erase)로 선택합니다. 돋보기는 원본 부분을 드래그하면 별도 확대 창이 생기고 원본·확대 창의 흰 핸들로 수정합니다. Spotlight는 밝힐 범위를 그리고 숫자 1~9로 어둡기를 바꿉니다. H 형광펜은 마커 선·자유 그리기·사각 영역과 끝 마감을 고릅니다. Ctrl+Enter로 마감을 전환합니다.

Ctrl+V로 현재 문서에 이미지 붙여넣기, Ctrl+O로 파일 추가, Ctrl+Shift+A로 새 캡처 추가를 합니다. 이미지의 이동·크기·불투명도를 바꾸고 더 큰 이미지는 캔버스를 확장합니다. 모서리는 비율 유지, Shift는 자유 변형입니다. 작은 도형도 가까운 핸들을 잡으며 커서 방향으로 조절 축을 확인할 수 있습니다. 곡선 화살표의 끝을 이동해도 휘어진 정도를 유지합니다. 추가와 캔버스 확장은 Undo 한 번으로 취소합니다. 전체 캔버스 보기로 자른 범위를 복원합니다.

모자이크·흐림·Erase는 드래그 중에도 실제 처리 미리보기를 표시합니다. 큰 영역은 최대 약 16만 픽셀의 축소 미리보기로 반응성을 확보하고 놓은 뒤 원래 해상도로 확정하므로 세부 무늬가 달라 보일 수 있습니다.

Erase는 주변 배경을 추정하므로 단색·그라데이션 화면에 적합하고 사진 질감 복원은 아닙니다. 흐림·모자이크·Erase 선택 후 텍스트만 처리는 OCR 단어 영역만 처리합니다. 인식 결과에 의존하며 작은 영역에서 사용하세요. 새 캡처 추가를 취소하면 기존 문서로 돌아갑니다.

## 배경 꾸미기·스포이트

편집창 왼쪽의 ▣ 버튼에서 그라데이션·단색·투명 배경, 여백, 둥글기, 그림자를 고릅니다. 화면에 바로 보이며 복사·저장·고정에 그대로 포함됩니다. ··· 메뉴의 내보내기 크기로 200% 화면 캡처를 절반 크기로 보낼 수 있습니다.

I(스포이트)로 클릭하면 전경색, Shift+클릭하면 배경색을 고르고 HEX를 복사합니다. 패널에서 RGB·HSL·OKLCH를 복사하고 WCAG 2 대비와 APCA Lc를 확인합니다. 자르기 모드에서는 방향키·Alt+방향키·[ ]·A로 범위를 다듬고, Ctrl+2는 선택 영역을 확대합니다.

## 스크롤 캡처

**자동**: 스크롤 캡처로 영역을 고르고 Enter를 누른 뒤 진행 창의 자동 스크롤을 누르면 Snaplet이 해당 창을 끝까지 스크롤하며 이어 붙입니다. 고정 헤더·푸터는 한 번만 남깁니다. 관리자 권한 앱처럼 Windows가 입력을 막는 경우에는 수동 모드를 사용하세요.

**수동**:

1. 트레이의 스크롤 캡처로 같은 모니터 안의 영역을 선택합니다.
2. 대상 앱에서 아래로 조금 스크롤합니다. 이전 내용이 절반 이상 남도록 겹쳐 주세요.
3. F8 또는 진행 창의 프레임 추가 버튼을 누릅니다. 화면이 멈춘 뒤 추가하세요.
4. 필요한 만큼 반복하고 F9 또는 완료를 누릅니다. 취소하면 버립니다.

반복 무늬, 영상, 늦게 나타나는 내용은 정합 실패를 유발할 수 있습니다. 확신이 낮은 프레임은 추가하지 않습니다. 기본 상한은 256MiB·높이 32,768px입니다. F8/F9가 이미 사용 중이면 버튼을 사용하세요.

## 처리와 보관

캡처와 OCR은 로컬에서 처리하며 업로드 기능은 없습니다. 최근 이미지는 메모리에 최대 12장/약256MB로 보관하며 앱 종료 시 사라집니다. 설정 → 저장에서 디스크 보관을 켜면 원본 12장을 `%LOCALAPPDATA%\Snaplet\History`에 남기고, 끄면 지웁니다. 자동 저장을 켠 경우 파일은 지정 폴더에 남습니다. 드래그한 PNG는 `%LOCALAPPDATA%\Snaplet\Drag`에 잠시 남고, 24시간이 지난 파일은 다음 시작 시 정리합니다. 설정은 `%LOCALAPPDATA%\Snaplet\settings.json`에 있습니다.

## 현재 확인 범위

이 배포는 **Windows x64 개발 버전**입니다. GitHub Actions에서 Windows 빌드·합성 편집 렌더링·네이티브 OCR·GDI 픽셀 검사를 수행합니다. 실제 PC의 캡처·입력·포커스·속도는 별도 확인이 필요합니다. 전자서명은 하지 않았습니다.

SDR 출력만 제공하며 HDR 색 보존은 미지원입니다. 영역 선택은 모니터 하나 안에서만 가능합니다. 보호 콘텐츠·최소화 창·잠금 화면은 캡처할 수 없거나 비어 보일 수 있습니다. 편집 객체를 담은 프로젝트 파일 저장, 여러 모니터에 걸친 영역 선택, 클라우드 업로드는 아직 없습니다. 명령줄 `Snaplet.exe --command region`으로 런처에서 캡처를 시작할 수 있고, 설정에서 `snaplet://` 링크를 허용할 수 있습니다.

영역 캡처는 GDI snapshot 우선이며 실패 시 WGC로 전환합니다. 지연 로그는 `%LOCALAPPDATA%\Snaplet\logs\capture-performance.jsonl`에 화면 내용 없이 남습니다. [캡처 엔진 비교 안내](https://github.com/sabsalee/snaplet/blob/main/docs/capture-performance.md)를 참고하세요.

시작 화면의 캡처 카드에는 현재 설정한 단축키가 표시됩니다. 최근 캡처를 클릭하면 편집할 수 있습니다. OCR 결과 창에서는 글자를 수정하고 줄바꿈을 합친 뒤 복사할 수 있습니다.
