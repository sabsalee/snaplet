# 검증

공통 모델·픽셀 처리 검사는 `tests/Capture.Core.Tests`, 실제 WPF 렌더링과 좌표·명령 경로 검사는 `--self-test`에서 실행합니다. 합성 이미지만 사용하며 데스크톱을 읽거나 클립보드에 쓰지 않습니다.

`artifacts/smoke-results/`에 편집·UI·업데이트 검사 JSON과 화면 PNG를 남깁니다. `--ocr-test`는 번들 한국어·영어 모델의 네이티브 로드를 확인합니다.

업데이트 검사는 다음을 분리합니다.

1. 상태·동시 실행·실패 복구·취소·사용자 재시작 동작과 실제 설정 화면.
2. Windows 설치 프로그램으로 시험 버전을 설치하고 손상된 패키지를 거부한 뒤 정상 버전 다운로드·디렉터리 교체·재시작·설정 보존까지 실행하는 통합 검사.

두 번째 검사는 일회용 GitHub Actions Windows 러너에서만 실행합니다. 캡처·편집 검사는 물리 마우스/키보드, 실제 한글 IME, 모니터 간 DPI 이동이나 화면 캡처 지연 측정이 아닙니다. 이 항목은 [실사용 확인](runtime-validation.md)을 따릅니다.

배포는 Windows 검사가 통과한 태그에서만 수행합니다. 네트워크나 다운로드 검증이 실패해도 현재 앱은 유지하고 다시 시도할 수 있습니다.
