## 돋보기 · G

확대할 원본 부분을 드래그한다. 오른쪽 아래에 기본 3배의 별도 확대 창과 연결선이 생긴다. 클릭만 하면 작은 원본 영역을 기본값으로 만든다.

- 원본 테두리 안쪽이나 가운데 흰 핸들을 끌면 샘플 위치를 바꾼다. 샘플 영역의 변·모서리 핸들은 샘플 범위를 바꾼다.
- 확대 창을 끌면 표시 위치만 옮긴다. 원본 샘플은 같은 곳을 가리킨다.
- 확대 창 핸들 또는 배율 슬라이더로 1~8배를 조정한다. 사각형/원형, 테두리 색·굵기를 바꾼다.
- 확대 창이 기존 화면 밖으로 나가면 캔버스를 넓힌다. 창과 샘플의 수정·복제·Undo를 지원한다.

돋보기는 그 아래의 합성 내용에서 샘플링하며 삽입 이미지도 확대한다. 다른 돋보기를 다시 확대하는 재귀 샘플링은 제외했다. 3배 기본값·연결선 비율은 관찰에 근거한 독립 구현이다.

## Spotlight · S

밝게 남길 영역을 드래그한다. 사각형/타원과 어둡기를 바꿀 수 있다. 선택한 상태에서 **숫자 1~9**를 누르면 주변 어둡기가 10~90%로 바뀐다. 여러 영역은 합쳐진 한 개의 마스크로 처리하므로 겹치는 부분이 어두워지지 않는다. 어둡기는 현재 문서의 Spotlight에 함께 적용된다. 테두리로 선택하거나 흰 핸들로 크기를 바꾼다.

이 구현은 추가 이미지와 주석까지 포함한 합성 문서를 강조한다.

## 형광펜 · H

기본은 드래그 시작·끝을 잇는 두꺼운 반투명 마커 선이다. 속성에서 **마커 선 / 자유 그리기 / 사각 영역**을 고른다. 색·굵기, 평평한/둥근/손그림 끝 마감을 지원한다. 선택한 마커에서 **Ctrl+Enter**로 마감을 순환한다. 마커 선은 두 끝점 핸들로 수정한다. 자유 그리기는 샘플 점을 부드럽게 이어 그린다.

원본에서 두꺼운 선과 마감 전환을 직접 확인했고, 자유 그리기·사각 모드는 함께 제공하는 추가 선택지다. 마감의 세부 수식은 독립 구현이다.

## Erase · E

없앨 내용 주변을 포함해 사각 영역을 드래그한다. 영역 밖 배경을 샘플링해 색과 완만한 그라데이션을 추정하고 그 배경으로 내부를 복원한다. 단색으로 덮는 도구와 다르며, 입력 이미지와 이전 합성 내용은 그대로 보관한다. 이동·크기 변경·Undo/Redo를 지원한다.

단색 UI 배경·완만한 그라데이션에서 사용한다. 사진 질감이나 복잡한 무늬를 생성하는 도구는 아니다. 주변 배경을 관찰할 수 없는 전체 이미지 선택은 원본을 유지한다.

흐림·모자이크·Erase를 선택하면 **텍스트만 처리** 버튼이 나타난다. 로컬 한글·영문 OCR로 찾은 단어의 사각 영역에만 효과를 적용한다. 한 번에 최대 200개 영역이며 작은 범위를 권장한다. 인식 결과에 따라 글자를 놓치거나 주변 요소를 포함할 수 있다. 처리 중 문서를 변경하거나 다른 객체를 선택하면 오래된 결과를 취소한다. 변환 전체는 Undo 한 번으로 취소한다.

원본은 삽입 이미지의 픽셀 효과에 Rasterize가 필요한 경우가 있지만, Snaplet은 추가 이미지에도 효과를 바로 적용한다.

## 이미지 붙여넣기·파일 추가·캡처 추가

- **Ctrl+V:** 클립보드 이미지를 현재 문서에 이미지 객체로 추가한다. 탐색기에서 복사한 이미지 파일도 지원한다.
- **Ctrl+O:** 이미지 파일을 현재 문서에 추가한다.
- **Ctrl+Shift+A:** 편집창을 잠시 숨기고 영역 캡처한다. 완료하면 같은 문서로 돌아와 추가한다. Esc 취소 시 문서와 기존 창을 복원한다. 새 캡처의 자동 복사·자동 저장·미리보기 설정은 이 삽입 동작에 적용하지 않는다.

이미지는 원본 픽셀 배율로 삽입한다. 더 큰 이미지는 캔버스를 자동 확장하며 음수 좌표도 지원한다. 이미지 객체를 드래그해 옮기고, 핸들로 크기를 바꾸며, 속성에서 불투명도를 조정한다. 모서리는 기본으로 비율을 유지하고 Shift를 누르면 자유 변형한다. 변 핸들은 한 방향 크기만 바꾼다. Alt+드래그 또는 Ctrl+D로 복제한다. 추가 이미지들은 일반 주석 아래에 놓이며 서로의 삽입 순서는 유지한다.

추가·캔버스 확장은 Undo 한 번으로 되돌린다. 자른 범위 복원 메뉴는 **전체 캔버스 보기**다. 확대된 부분의 빈 영역은 PNG에서 투명하고 JPEG에서는 흰색이다.

## 문서 수명과 한도

이미지 픽셀은 불변 자산으로 보관하고 Undo·복제 시 공유한다. 캔버스/이미지 하나는 64MP 이하, 캔버스 한 변은 32,768px 이하로 제한한다. 한 문서의 이미지 자산과 관련 Undo 기록은 256MB 한도에서 오래된 기록을 정리한다. 객체 편집 상태는 앱 종료 후 유지되지 않으므로 PNG/JPEG 결과를 저장해야 한다.

Windows 자동 검사는 합성 이미지의 실제 WPF 픽셀·좌표·레이어·OCR·Undo를 확인한다. 물리 입력·실제 화면 캡처 취소·혼합 DPI는 실사용 확인 범위로 남긴다.
