# 변경 사항

## 0.8.1

- 둥글기 조절점을 도형 바깥으로 옮기고 연결선을 표시해 글자와 조절점이 겹치지 않게 개선.
- 작은 객체에서는 겹치는 둥글기 조절점을 숨기고 속성 수치 입력을 유지.
- 기존 글자 입력·더블클릭 편집의 우선순위를 명확하게 개선.

## 0.8.0

- Microsoft Fluent 벡터 아이콘을 공통 24 px 격자로 통일.
- 선택 전 호버 테두리·이동/텍스트 커서, 선택 테두리와 조절점별 안내.
- 파란 원으로 말꼬리 이동, 민트색 마름모로 모서리 둥글기 직접 조절.
- 말풍선 꼬리의 곡선 연결과 너비 조절, 모서리 둥글기 조절.
- 도구별 미리보기 프리셋과 개선된 기본 색상·굵기.
- 입력 중에도 말풍선 배경·꼬리를 유지하고, 새 긴 말풍선의 기본 꼬리가 몸통에 묻히지 않게 배치.
- 캔버스를 가리지 않는 속성 행, 크기 수치, 기존 텍스트 더블클릭 편집.

## 0.7.0

- GitHub Releases 기반 자동 업데이트와 설치 프로그램.
- 시작 후 및 6시간마다 버전 확인·다운로드. 설정에서 끌 수 있으며 재시작은 사용자가 선택.
- 파일 크기·해시 검증, 다운로드 실패 복구, 중복 실행 방지, 설치된 앱의 버전 교체·재시작 검사.
- 기존 설정 폴더를 유지하고 캡처·저장·복사 중 재시작을 방지.
- 영역·창·모니터 캡처, 미리보기·고정, 이미지 편집·OCR·수동 스크롤 캡처.
- 곡선 화살표·말풍선·번호·도형 꼬리, 형광펜·돋보기·Spotlight·Erase, 이미지 추가와 Undo/Redo.
- 포인터 기준 확대, 연속 방향키 Undo, 경계 드래그·자동 스크롤, 긴 텍스트와 효과 미리보기.
