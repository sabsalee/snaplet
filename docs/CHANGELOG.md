# 변경 사항

## 0.7.0

- GitHub Releases 기반 자동 업데이트와 설치 프로그램.
- 시작 후 및 6시간마다 버전 확인·다운로드. 설정에서 끌 수 있으며 재시작은 사용자가 선택.
- 파일 크기·해시 검증, 다운로드 실패 복구, 중복 실행 방지, 설치된 앱의 버전 교체·재시작 검사.
- 기존 설정 폴더를 유지하고 캡처·저장·복사 중 재시작을 방지.
- 영역·창·모니터 캡처, 미리보기·고정, 이미지 편집·OCR·수동 스크롤 캡처.
- 곡선 화살표·말풍선·번호·도형 꼬리, 형광펜·돋보기·Spotlight·Erase, 이미지 추가와 Undo/Redo.
- 포인터 기준 확대, 연속 방향키 Undo, 경계 드래그·자동 스크롤, 긴 텍스트와 효과 미리보기.
