# 변경 사항

## 다음 버전

- **올인원 캡처 막대 (설정에서 켜기)**: 선택 화면 위쪽에서 영역·창·화면·전체 화면·3초 후·스크롤·텍스트 캡처를 바로 고르고, 영역의 비율을 1:1, 4:3, 3:2, 16:9로 고정. 설정 → 캡처에서 켬.
- **실시간 선택**: 화면을 멈추지 않고 영역을 고른 뒤, 고른 순간의 화면을 캡처. 선택 화면에서 F나 올인원 막대로 고정과 실시간을 전환하고, 기본값은 설정 → 캡처에서 바꿈. 고정 상태에서 F를 누르면 그 순간의 화면으로 다시 멈춤. 확대경·측정자·색 복사·내용에 맞춤은 고정 상태에서만 사용.
- **캡처 기록**: 지난 캡처를 날짜별로 모아 보는 창. 클릭하면 편집하고, 오른쪽 클릭으로 복사·저장·삭제. 트레이 메뉴, 시작 창의 최근 캡처, 지정한 단축키로 염. 디스크 보관을 켜면 최근 12개 대신 200개를 남김. 기본값은 지금처럼 꺼져 있음.
- **프로젝트 파일**: 편집창의 더보기 → "프로젝트로 저장"으로 원본과 편집 객체를 `.snaplet` 파일에 담아, 다시 열어도 객체를 계속 고칠 수 있음. 이미지 열기, 끌어다 놓기, 실행 인수로 열림. 실행 취소 기록은 저장하지 않음.
- **가로 스크롤 캡처**: 스크롤 캡처 창에서 "오른쪽으로"를 고르면 옆으로 긴 화면을 이어 붙임. 수동과 자동 모두 지원하고, 고정된 사이드바는 한 번만 담음. 자동 스크롤 입력에 반응하지 않는 앱에서는 "끝까지 담았습니다" 대신 수동으로 이어 가라고 안내.
- **흐린 이미지 배경**: 배경 꾸미기에서 이미지 자체를 흐리게 늘린 배경을 고를 수 있음. 자르기 범위를 따라가고, 미리보기와 내보낸 결과가 같음.
- **창 캡처 배경 바꾸기**: 그림자·배경을 자동으로 넣는 창 캡처를 편집창에서 열면, 배경이 이미지에 굳지 않고 배경 꾸미기 설정으로 열려 다른 배경으로 바꾸거나 끌 수 있음.
- **편집창에 이미지 끌어다 놓기**: 이미지 파일이나 그림을 편집창에 놓으면 놓은 자리에 추가. 캔버스 밖으로 나가지 않고, 가장자리·가운데·다른 객체에 가까우면 맞춤. 객체를 옮길 때도 캔버스 가장자리·가운데에 맞춤.
- **WebP·HEIC 열기**: 이미지 열기, 시작 창·편집창 끌어다 놓기, 이미지 추가에서 WebP·HEIC를 엶. Windows 확장이 없으면 설치할 확장 이름을 알려 줌. 휴대폰 사진의 회전 정보(EXIF)를 반영해 바로 세워 엶.
- **보조 창 테마**: 설정·스크롤 캡처·텍스트 추출·알림 창이 항상 어둡던 것을 Windows 앱 테마(밝게/어둡게)를 따르도록 바꿈. 이미지 위에 뜨는 캡처 후 팝업은 그대로 어둡게 유지.
- **아이콘 정리**: 시작 창의 3초 타이머는 타이머, 캡처 기록은 기록 아이콘으로 구분. 설정의 단축키·업데이트·정보 페이지에 각각 키보드·동기화·정보 아이콘.
- **설정 배치**: "기본 글꼴"을 캡처 후 동작에서 편집과 텍스트 묶음으로 옮김.
- **글자 입력 취소**: Esc로 취소하면 입력 중 바꾼 서식도 함께 되돌림.
- **납작한 캡처의 팝업**: 이미지가 얇아도 팝업 영역 전체에서 호버가 됨.

## 0.11.2

- **입력 중 글자 서식**: 글자를 입력하는 동안에도 속성 패널에서 색·크기·글꼴·정렬을 바꿀 수 있음. Ctrl+B·I·U로 굵게·기울임·밑줄 전환. Esc로 취소하면 서식 변경도 함께 취소.
- **배경 꾸미기 패널**: 팝업 대신 이미지 왼쪽에 패널로 열려 결과를 보면서 조절함.
- **여백 균형 맞추기**: 이미지 안의 단색 여백을 위아래·좌우 같게 잘라 내용을 가운데에 둠.
- **내 스타일**: 배경 모양을 최대 8개까지 저장해 다른 캡처에서도 사용.
- **편집창 위치**: 작은 화면에서 창이 작업 표시줄 뒤로 넘어가 저장 버튼이 가려지던 문제 수정.
- **캡처 팝업·고정 이미지**: 팝업의 긴 툴팁이 복사·저장을 가리지 않게 하고, 넓은 고정 이미지의 도구를 이미지에 붙여 표시.

## 0.11.1

- **글자 입력**: 새 글자를 놓으면 바로 입력되도록 수정. 지금까지는 포커스가 들어가지 않아 한 번 더 클릭해야 했고, 그 클릭으로 "텍스트"가 지워지지 않고 뒤에 이어 붙었음.
- **한글 입력 모드의 단축키**: 한글 모드에서도 V·T·M·Ctrl+Z 같은 글자 단축키가 동작하도록 수정.
- **캡처 팝업**: 가로·세로로 긴 캡처의 검은 띠를 없애고, 작은 캡처를 늘리지 않음. 크기 표시와 파일 손잡이가 겹치지 않게 하고, 복사·저장에 마우스를 올려도 글자가 잘 보이게 함.
- **고정 이미지**: 폭 360으로 늘리는 대신 캡처 크기 그대로 고정하고(큰 캡처는 처음 폭 640) 검은 띠를 없앰. 납작한 이미지는 도구가 이미지를 가리지 않고 위아래에 나타남.
- **아이콘**: 앱 아이콘을 새로 만들고 트레이에서도 사용. 지금까지 트레이는 Windows 정보 아이콘, 앱은 기본 아이콘이었음.
- **트레이 메뉴**: Windows 밝기 설정을 따르고 왼쪽 흰 띠를 없앰. 고정 이미지가 있으면 "고정 이미지 모두 닫기"가 나타남. 오른쪽 클릭 메뉴의 띠도 함께 사라짐.
- **창 캡처**: 바탕화면이 "Program Manager" 대신 "바탕화면"으로 표시됨.

## 0.11.0

- **캡처 후 오버레이**: 평소엔 이미지만 표시하고, 마우스를 올리면 가운데 복사·저장, 네 모서리에 닫기·고정·편집·OCR이 나타남. 여러 개가 겹치지 않게 쌓이고(최대 5개) 닫은 팝업은 트레이에서 다시 열 수 있음. 오른쪽 클릭 메뉴에 회전·기본 앱으로 열기·모두 닫기 추가.
- **편집창 하단 막대**: 왼쪽에 이미지 크기·확대율, 가운데에 끌어서 놓기, 오른쪽에 고정·복사·저장. 위쪽에는 자르기와 배경 꾸미기.
- **회전·뒤집기**: ≡ 메뉴에서 객체를 합쳐 새 편집창으로.
- **자르기 비율 고정**: ≡ 메뉴에서 1:1, 4:3, 3:2, 16:9, 9:16.
- **내 색상**: 색상 창에 현재 색을 저장(최대 12개). 오른쪽 클릭으로 삭제.
- **글자 스타일**: 외곽선 글자, 고정폭 글자, 고정폭 상자 추가.
- **모자이크**: 블록마다 작은 임의 밝기 차이를 더해 같은 글자가 같은 블록이 되지 않게 함.
- **고정 이미지 방향키**: 클릭 후 방향키로 1px, Shift로 10px 이동.
- **Alt로 창 유지**: 편집창에서 Alt를 누르고 복사·저장하면 창을 닫지 않음.
- **고정 이미지**: 끌면 창이 이동하고, 파일 전달은 도구의 손잡이로 분리. 불투명도가 실제로 적용되도록 고치고 슬라이더와 +/− 크기 버튼 추가.
- **글자**: 새 글자는 선택된 "텍스트"로 시작해 바로 입력하면 바뀌고, 그대로 두면 그 글자가 삽입됨. 굵게·기울임·밑줄과 왼쪽·가운데·오른쪽 정렬 추가.
- **번호**: 누른 채 끌면 삽입과 동시에 포인터 방향을 지정. 실행 취소 한 번으로 함께 취소.
- **Erase 제거**: 복잡한 화면에서 도형으로 가리는 것과 큰 차이가 없어 도구를 없앰. 범위 상자의 Delete는 범위 취소로 변경.
- **창 캡처**: 활성 창을 바로 찍는 대신 캡처할 창을 클릭해 고름.

## 0.10.0

- **트레이에서 시작**: 실행해도 창을 띄우지 않고 트레이에서 시작. 처음 한 번만 "트레이에서 실행 중" 알림과 영역 캡처 단축키를 보여 줌. 트레이 아이콘 왼쪽 클릭은 메인 창, 오른쪽 클릭은 메뉴.
- **빈 편집창이 메인 창**: 카드가 많던 시작 화면 대신 편집창과 같은 툴바·작업 영역에 안내만 있는 빈 창. 캡처 6종·이미지 열기·클립보드 버튼, 드래그 앤 드롭, Ctrl+V·Ctrl+O, 최근 캡처 메뉴. 이미지가 들어오면 같은 위치·크기의 편집창으로 바뀜.
- **로그인 시 자동 실행**: 설정 → 단축키에서 켜면 HKCU Run 키에 등록해 로그인 때 트레이에서 시작(기본 꺼짐, 관리자 권한 불필요).
- **선택 모드 범위 지정**: 선택 도구(V)에서 빈 곳을 드래그하면 크기 표시가 붙은 범위 상자가 생김. 상자 안 드래그로 이동, 조절점으로 크기 조절, Enter 자르기, Delete 지우기(Erase 객체로 바뀌어 채움 방식 변경 가능), Esc 취소. 방향키·Alt+방향키·[ ]·A 맞춤·Ctrl+2도 자르기 범위와 같이 동작.
- **툴바 도구 펼침**: 편집창이 넓으면 흐림·Erase·형광펜·Spotlight·번호·타원·선·돋보기·불투명 가림까지 툴바에 모두 표시. 좁아지면 뒤쪽 도구부터 ··· 안으로 접히고, ···에서 고른 도구가 그 앞 칸에 나타남. ··· 메뉴는 캡처 추가·이미지 붙여넣기·이미지 파일 추가·스포이트와 접힌 도구만 보여 줌.
- 모자이크 도구 아이콘을 앱 목록처럼 보이던 네 칸 아이콘에서 체커보드 모양으로 교체.
- **캡처 후 작은 팝업**: 캡처가 끝나면 화면 구석 대신 마우스 포인터 오른쪽 아래에 작은 팝업이 뜸. 썸네일·크기·복사됨 표시와 편집·복사·저장·텍스트 추출·고정·닫기 버튼. 포커스를 가져가지 않아 바로 다른 앱에 붙여넣을 수 있고, 화면 끝에서는 왼쪽·위로 뒤집힘. 썸네일 드래그로 파일 전달, 바깥 클릭으로 닫기는 그대로.
- **화살표 모양**: 채운 화살표에 볼록·갈매기·리본 모양을 추가하고 속성 패널의 버튼 하나로 순환. 열린 촉과 가는 촉을 곧은 V로 바꿔 크기를 키움. 양방향은 채운 머리 + 굵은 몸통 대신 가는 선 + 양쪽 V 머리로 변경.
- **효과 도구**: Spotlight 기본 어둡기를 18%로 낮추고 색·굵기를 고를 수 있는 테두리 추가. 돋보기 기본을 곡선 렌즈로 바꾸고 흰 외곽선 제거, 원본 표시와 연결선도 같은 굵기로. Erase는 줄무늬·표·체커처럼 부드러운 배경이 맞지 않는 곳에서 가장자리 무늬를 이어 채움.
- **이미지 추가**: 캡처보다 큰 이미지를 넣으면 캔버스를 키우는 대신 캡처 크기에 맞춰 줄여 투명 여백이 생기지 않음. 복제와 이동도 캔버스를 키우지 않음.
- **글자 도구**: 기본을 글자만으로 변경하고, 글자만·배경 있는 글자·말풍선(말꼬리)을 속성 패널에서 바로 전환. 글꼴 선택 추가. 기본 글꼴은 설정 → 캡처에서 지정하며 처음엔 Noto Sans KR(없으면 맑은 고딕).
- **캡처 후 팝업**: 이미지 모서리 닫기, 복사·저장·편집·OCR·고정 한 줄, 끌어서 파일로 놓는 손잡이, 마우스를 올린 버튼 이름 표시.
- **파일 드래그 손잡이**: 편집창 버튼을 양옆 점이 있는 손잡이 모양과 이동 커서로 변경.
- **아이콘**: 글자·타원·흐림·Spotlight·불투명 가림을 다시 그려 서로 구분되게 변경.
- **배경 꾸미기**: 복사·저장·고정 옆으로 버튼을 옮기고 켜져 있으면 강조. 미리보기에서 배경이 보기 영역 전체를 채우던 문제를 고치고 이미지를 가운데 배치.
- **이미지 크기**: 툴바의 이미지 크기를 눌러 25·33·50·100·200·400% 또는 가로·세로 픽셀로 내보내기 크기 지정. 비율 유지, 실행 취소 가능, 원본은 보존.
- **편집기 측정자**: ··· 메뉴 또는 U. 포인터 아래 같은 색 범위의 가로·세로 길이를 표시하고 클릭하면 복사. 저장 결과에는 포함되지 않음.
- **저장 파일 이름 규칙**: 설정 → 저장에서 `%Y %m %d %H %M %S %f %r`로 이름 규칙 지정. 편집창 저장 대화상자도 같은 규칙 사용.
- **인쇄**: ··· 메뉴 또는 Ctrl+P. 페이지보다 크면 줄이고 가운데 배치.
- **확대 단축키**: Z로 포인터 위치 200%와 화면 맞춤 전환, Q·W로 선택 영역의 왼쪽 위·오른쪽 아래 모서리를 픽셀 하나가 16배로 보이게 확대.
- **캡처 후 표시 설정**: 설정 → 캡처에서 "커서 옆 작은 팝업 / 바로 편집창 열기 / 아무것도 안 함" 선택. 기존 "캡처 미리보기" 끔 설정은 "아무것도 안 함"으로 옮겨짐(설정 스키마 3).

## 0.9.0

정밀 캡처와 결과물 꾸미기를 중심으로 한 대규모 업데이트입니다.

- **영역 선택 정밀 도구**: 픽셀 확대경(좌표·색), 십자선, Tab 색 복사(Shift+Tab rgb, C 평균색), R 측정자, Shift 정사각형, 드래그 중 Space 이동, 방향키로 포인터 1px 이동, 선택 없이 Enter로 현재 모니터 캡처.
- **놓은 뒤 조정**(설정 또는 Ctrl을 누른 채 놓기): 조절점·가장자리 드래그, 방향키 이동, Alt+방향키 크기, [ ] 확장·축소, A 내용에 맞춤, Enter·더블클릭 캡처.
- **텍스트·QR 바로 인식**: 영역을 고르면 QR·Data Matrix·Aztec·PDF417을 먼저 읽고, 없으면 OCR 결과를 클립보드에 복사. 기존 텍스트 추출도 QR을 함께 표시. 줄바꿈 합치기 설정.
- **자동 스크롤 캡처**: 선택 영역 아래 창에 휠 입력을 보내 끝까지 이어 붙임. 겹침에 맞춰 보폭 조절, 고정 헤더·푸터는 한 번만 남김, 끝 도달·최대 길이·연속 실패 시 멈춤. 수동 모드도 같은 헤더·푸터 처리.
- **배경 꾸미기**: 그라데이션 8종·단색·투명 배경, 여백, 둥근 모서리, 그림자. 편집창에서 실시간 미리보기, 복사·저장·고정에 포함, Undo 지원. 창 캡처에 그림자·배경을 자동으로 넣는 설정.
- **편집기**: 스포이트(HEX·RGB·HSL·OKLCH 복사)와 WCAG 2·APCA 대비 검사, 자르기 범위의 방향키·Alt+방향키·[ ]·A 맞춤, Ctrl+2 선택 영역 확대, 내보내기 크기(100/75/50/25%), Esc로 닫기(설정에 따라 복사·저장).
- **캡처**: 마우스 포인터 포함 옵션, 모든 화면·창 선택·스크롤·텍스트/QR·앱 열기 단축키(기본 미지정).
- **고정 이미지**: Shift+휠·버튼으로 불투명도, 클릭 통과(트레이 메뉴에서 해제).
- **보관·자동화**: 최근 캡처 12개를 디스크에 보관하는 옵션(기본 꺼짐), `Snaplet.exe --command region` 명령줄 실행, 선택형 `snaplet://` 링크.
- **설정 이전**: 설정 파일에 스키마 버전을 넣어 단축키가 늘어도 기존 설정을 유지. Backspace로 단축키 해제.
- 텍스트·사각형 콜아웃 꼬리의 돌출 길이를 몸통 크기에 따라 최대 24~48 이미지 픽셀로 제한. 조절점·선택·내보내기에 같은 제한 적용.
- **편집창 새 배치**: 밝은 한 줄 툴바(Windows 앱 모드의 밝게/어둡게를 따름), 오른쪽 위에 뜨는 아이콘 속성 패널(색·크기·스타일), 커서 아래 색·이미지 크기·확대율 표시, ··· 메뉴의 보조 도구, 새 선택 핸들.
- **기본 스타일 정비**: 첫 프리셋을 빨강 `#FF0C01` 기준으로 통일. 채운 화살표는 머리 크기를 유지하고 몸통만 늘어나며 짧은 화살표는 전체를 줄이고 긴 화살표는 꼬리를 가늘게 그림. 도형 3px 손그림·모서리 5, 말풍선 17px 세미볼드, 번호 지름 36px(클릭 지점이 포인터 끝), 형광펜 `#FFF68D`. 반투명 채움 30%.
- 고해상도 화면에서는 프리셋 크기에 화면 배율을 곱해 100% 화면과 같은 굵기로 보이게 함.
- 둥근 외곽선을 따라 꼬리 밑변을 배치하고 모서리 양쪽의 접선에 맞춰 연결해, 한쪽 변으로 길게 꺾이던 모양 개선.
