Windows 11 x64용 Snaplet 0.10.0 개발 버전입니다.

이번 버전은 캡처 후 포인터 옆 팝업, 트레이 시작과 로그인 시 실행, 글자 도구 개선(기본은 글자만, 글꼴 선택), 화살표 모양 4종, 이미지 크기 직접 지정, 편집기 측정자, 인쇄, 저장 파일 이름 규칙, Spotlight·돋보기·Erase 개선을 담았습니다. 큰 이미지를 추가할 때 투명 여백이 생기던 문제와 배경 꾸미기 미리보기가 보기 영역 전체로 늘어나던 문제도 고쳤습니다.

**자동 업데이트를 사용하려면 Setup.exe를 설치하세요.** 기존 ZIP 버전은 먼저 트레이에서 종료합니다. 이후 설정 → 업데이트에서 새 버전을 받고 원하는 때 다시 시작할 수 있습니다. 기존 설정은 유지되며 저장하지 않은 편집은 종료 시 사라지므로 먼저 내보내세요(최근 캡처 원본은 설정 → 저장에서 디스크 보관을 켤 수 있습니다).

ZIP 실행 버전도 제공하며 ZIP 전체를 풀어 Snaplet.exe를 실행합니다. ZIP 버전은 자동 교체하지 않습니다.

- 단축키 캡처·미리보기·고정·이미지 편집·한국어/영어 로컬 OCR.
- 곡선 화살표·말풍선·번호·도형·형광펜·돋보기·Spotlight·Erase.
- 정밀 영역 선택, QR 인식, 자동 스크롤, 배경 꾸미기, 스포이트·대비 검사.
- GitHub 업데이트 확인·다운로드·검증·설치·재시작, 기존 설정 보존.

게시 전 공통·WPF 편집·UI·OCR·업데이트 상태 검사와 Windows 설치/교체/재시작 검사를 수행합니다. 실제 한글 IME·물리 입력·혼합 DPI·사용자 PC의 캡처 지연은 별도 확인 항목입니다. 현재 개발 빌드는 미서명입니다.
