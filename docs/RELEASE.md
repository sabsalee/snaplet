Windows 11 x64용 Snaplet 0.13.0 개발 버전입니다.

앱 전체 모양을 다듬었습니다. 설정은 항목마다 있던 카드를 묶음별 목록 하나로 합치고 설명을 덜어 냈으며, Windows 11 글꼴과 글자 크기 체계, 32px 버튼을 씁니다. 캡처 기록과 시작 창의 썸네일, 선택 화면의 안내와 확대경도 둥근 모양으로 정리했습니다. 시작 창에서 연 편집창을 닫으면 시작 창이 다시 나타나고, 편집창을 열면 캡처 후 팝업이 편집창을 가리지 않으며, 프로젝트 파일 이름이 제목 표시줄에 보입니다.

**자동 업데이트를 사용하려면 Setup.exe를 설치하세요.** 기존 ZIP 버전은 먼저 트레이에서 종료합니다. 이후 설정 → 업데이트에서 새 버전을 받고 원하는 때 다시 시작할 수 있습니다. 기존 설정은 유지되며 저장하지 않은 편집은 종료 시 사라지므로 먼저 내보내세요(최근 캡처 원본은 설정 → 저장에서 디스크 보관을 켤 수 있습니다).

ZIP 실행 버전도 제공하며 ZIP 전체를 풀어 Snaplet.exe를 실행합니다. ZIP 버전은 자동 교체하지 않습니다.
