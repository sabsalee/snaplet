트레이 오른쪽 클릭 메뉴를 간소화하고, 캡처·녹화 방식을 한곳에서 고르는 캡처 도구 모음을 추가했습니다(트레이 메뉴나 단축키로 열기). 녹화 범위는 네 모서리 꺾쇠와 바깥을 옅게 어둡게 해 표시하고, 녹화 중 그리기가 빈 화면에서 시작되지 않던 문제를 고쳤습니다. 캡처 후 팝업은 편집 버튼 위치와 텍스트 추출 아이콘을 바꿨고, 편집창은 하단 바를 없애 고정·복사·저장을 위쪽 도구 막대로, 이미지 크기·확대율을 캔버스 오른쪽 아래로 옮겼습니다. 화면 녹화는 계속 시험 기능입니다.

**자동 업데이트를 사용하려면 Setup.exe를 설치하세요.** 기존 ZIP 버전은 먼저 트레이에서 종료합니다. 이후 설정 → 업데이트에서 새 버전을 받고 원하는 때 다시 시작할 수 있습니다. 기존 설정은 유지되며 저장하지 않은 편집은 종료 시 사라지므로 먼저 내보내세요(최근 캡처 원본은 설정 → 저장에서 디스크 보관을 켤 수 있습니다).

ZIP 실행 버전도 제공하며 ZIP 전체를 풀어 Snaplet.exe를 실행합니다. ZIP 버전은 자동 교체하지 않습니다.
