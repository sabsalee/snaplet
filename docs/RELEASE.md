Windows 11 x64용 Snaplet 0.11.2 개발 버전입니다.

글자를 입력하는 동안에도 속성 패널에서 색·크기·글꼴·정렬을 바꿀 수 있고, Ctrl+B·I·U로 굵게·기울임·밑줄을 전환합니다. 배경 꾸미기는 이미지 왼쪽 패널로 옮겼고, 이미지 안의 단색 여백을 맞추는 "여백 균형 맞추기"와 배경 모양을 저장하는 "내 스타일"을 추가했습니다. 작은 화면에서 편집창이 작업 표시줄 뒤로 넘어가던 문제도 고쳤습니다.

**자동 업데이트를 사용하려면 Setup.exe를 설치하세요.** 기존 ZIP 버전은 먼저 트레이에서 종료합니다. 이후 설정 → 업데이트에서 새 버전을 받고 원하는 때 다시 시작할 수 있습니다. 기존 설정은 유지되며 저장하지 않은 편집은 종료 시 사라지므로 먼저 내보내세요(최근 캡처 원본은 설정 → 저장에서 디스크 보관을 켤 수 있습니다).

ZIP 실행 버전도 제공하며 ZIP 전체를 풀어 Snaplet.exe를 실행합니다. ZIP 버전은 자동 교체하지 않습니다.
